Dùng Transpose với Manokara

Transpose là tiện ích trình duyệt để đổi tông, chỉnh tốc độ và lặp đoạn nhạc. Manokara dùng profile trình duyệt riêng, nên cần cài extension vào đúng profile này một lần.

  1. Cài Transpose trong profile Manokara bằng nút bên dưới.
  2. Mở Manokara trong cửa sổ trình duyệt có thanh công cụ.
  3. Phát bài hát ở cửa sổ đó rồi mở biểu tượng Transpose trên thanh công cụ.

Nếu Transpose không nhận video nhúng, hãy cấp quyền cho trang Manokara và YouTube; sau đó thử chế độ Tab Audio trong Transpose. Cửa sổ mới dùng cùng profile, nhưng bạn cần bấm Play trong cửa sổ đó.

OBS relay needs the Manokara server. This app is open as file://, so OBS cannot receive live lyrics. From the project folder run python .\outputs\manokara_server.py, then open http://localhost:8000/manokara.html. Do not use python -m http.server for OBS; it does not provide the lyric relay.
