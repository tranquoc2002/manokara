Use Transpose with Manokara

Transpose is a browser extension for pitch, speed, and loops. Install it in the browser profile you use for Manokara.

  1. Install Transpose using the button below.
  2. Open Manokara in a browser window with the extension toolbar visible.
  3. Play a song, then open Transpose from the toolbar.

If the extension does not detect embedded video, allow access to Manokara and YouTube, then try its Tab Audio mode. A new window uses your current browser profile.

Open Manokara through its configured server URL. The lyric relay requires the Python server. See DEPLOY.md for setup.
